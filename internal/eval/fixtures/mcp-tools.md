# MCP Tools

Cerebra exposes its memory over an MCP server. The search tool runs a semantic
search across indexed content. The list_brains tool returns the known agent
brains. The search_agent tool searches a single agent's recorded invocations,
and list_agent_activity lists recent activity for an agent.

A CISO or developer evaluating Cerebra uses these MCP tools to retrieve evidence
from prior agent sessions before answering a question.
